Three steps, one of them yours

The extension reads the Amazon pages you already have open and writes to the Goodreads account you're already signed in to. You stay in charge of what gets shelved.

  1. Scan

    Reads your cart, Save for Later, and wish lists. Automatically, as you open them, if you like. Results from several lists accumulate.

  2. Review

    Books it's confident about arrive pre-checked. The USB cable in your cart shows up unchecked and labelled, rather than quietly dropped.

  3. Shelve

    Confirmed books land on Want to Read and clear off the list. Optionally they leave your Amazon cart too.

There is no server to trust

Not "we don't look at your data" — there is nowhere for it to go. The extension runs inside the sessions you're already signed in to, so it never sees a password, and no part of it phones home.

Two ways onto the shelf

Default

Straight to Goodreads

Each book is searched and shelved for you, paced politely. The queue is saved after every book, so an interrupted run picks up where it stopped rather than starting over.

Fallback

CSV import

Goodreads' own import format, for when their site changes underneath us or you have hundreds of books at once.

Why an extension, and not a website?

Goodreads retired its public API in December 2020 and issues no new keys. Amazon has never exposed a personal cart to third parties. A website would have to ask for both your passwords. An extension asks for neither.

What happens when Goodreads changes their site?

The automatic path breaks and every book routes to the CSV import instead, which uses a documented, stable format. You lose convenience, not books.

Will it delete things from my Amazon account?

Only if you tick the box, and only books Goodreads confirmed, and only from the cart and Save for Later. Wish lists are never touched.
